# DumpFirstLevel_allChannels (na model)

Dump the non-amplitude-modulated (na) first-level beta coefficients onto CSV
files for own 2nd level analysis without using AFNI 3dttests. Same tooling
as 04_secondlevel_group/dumpFirstLevel_betaCoefs, pointed at the na model's
stats.*.na.nii.gz buckets (see ../../03_firstlevel_glm/first_level_glm_na.sh).

na bucket sub-brick indices (0-based, via `3dinfo -label`):

    9  = na-hard-easy_GLT#0_Coef   (hard blocks b3,b4 vs easy blocks b1,b2)
    11 = na-corsi_GLT#0_Coef       (mean of b1-b4)

main program:

        ./dumpBetaCoefs_allChannels.sh <group1 sublist> <group1 label> <group2 sublist> <group2 label> <volume idx> <output filename>

the following support programs are needed for the main program to run:

* grab_betas.sh
  * Grabs 1st level beta coefs from 1 channel

* add_covariates.py
  * Adds covariates in covariates file (path hard-coded in the support program) to the csv

* merge_channel_dumps.py
  * Takes temporary csv single channel dumps from the output of grab_betas.sh
    and merge them into the final output csv

The post-processing program relabel_groups.sh can be called on the final output csv to relabel the csv.

Group sublists (con.hbo.na.sublist.txt, lrv.hbo.na.sublist.txt,
pcon.hbo.na.sublist.txt) are copied from ../ (generated by
../update_sublists_na.sh) and only include subjects whose na GLM actually
completed - see ../../notes.txt (2026-08-17) for the 9 subjects excluded due
to truncated scans.

## covariate file

The canonical data_aux/select.cov.1D on this mount is stale (dated
2024-12-21, only has X sans saps dose) - it predates the wais_matrix/sud
columns that 04_secondlevel_group/dumpFirstLevel_betaCoefs/prep_select_cov.py
merges in from covars.1D and the Mindata xlsx. Rather than touch that shared
canonical file, prep_select_cov_na.py builds a local select.cov.na.1D (same
6 columns: X sans saps wais_matrix sud dose) from the same local source
files, used by dumpBetaCoefs_allChannels.sh here.

## group-level comparisons

run_all_analyses_na.sh runs analyze_psd_agg_vs_psd_nagg.py (copied unmodified
from 04_secondlevel_group/dumpFirstLevel_betaCoefs/ - ANCOVA + Mann-Whitney,
FDR-BH/Hochberg/Hommel, permutation max-stat and cluster-based permutation,
all channel-wise) over all 3 group pairs x 2 na contrasts (hard-easy, corsi):

  - sans/saps are never used as covariates
  - HC comparisons (vs con): covariates = wais_matrix, sud (dose dropped -
    all HC have dose=0, perfectly collinear with group)
  - PSD+AGG vs PSD-AGG (no HC involved): covariates = wais_matrix, sud, dose

Output: results_<pair>_na_<contrast>/ (per-channel CSV + interactions CSV +
figures). As of the 2026-08-17 run, no channel survives any correction
method (FDR-BH, Hochberg, Hommel, permutation max-stat, or cluster
permutation) in any of the 6 comparisons - null result, consistent with the
amplitude-modulated model's prior analysis.
